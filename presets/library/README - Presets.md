Every look comes as 5 variations built for different lighting, so a whole wedding can be graded with ONE look.
Studio, World and Glamour looks use the wedding variations below; Landscape looks use landscape variations (01 Signature, 02 Golden Hour, 03 Blue Hour Night, 04 Overcast Mist, 05 Dramatic) and Street looks use street variations (01 Signature, 02 Harsh Sun, 03 Night Neon, 04 Overcast Flat, 05 Punchy) and Portrait looks use portrait variations (01 Signature, 02 Window Light, 03 Studio Flash, 04 Soft Beauty, 05 Editorial Punch); none of these three writes Exposure, Temperature or Tint:

| Variation | Use it on |
|---|---|
| 01 Signature | The core look - general purpose, start here |
| 02 Daylight Bright | Outdoor day, haldi / mehendi, bright venues - lifts exposure, tames highlights |
| 03 Reception Night | Indoor LED / tungsten / low light - opens shadows, protects highlights, pulls saturation off orange/yellow so skin does not go orange |
| 04 Soft Matte | Gentle faded version - couple portraits, bride getting ready, soft window light |
| 05 Rich | Punchier, deeper version - editorial hero frames, decor, colourful outfits |

## Technical

- Built and tested on Nikon raw files (NEF). Also work on other raw formats and JPEGs, but verified on Nikon.
- Adobe Color profile, Process Version 15.4 (Lightroom Classic 13+, Lightroom, Camera Raw 16+).
- White balance is never changed: no preset writes Temperature or Tint, so your As-Shot or custom WB stays exactly as you set it.
- Sharpening, noise reduction, lens corrections, crop and masks are not touched.
- Skin: every one of the 500 variations was checked on 13 real wedding raws (tungsten, LED, daylight, shade, harsh sun, night); median
  skin hue stays in the natural 19-31 degree band with no orange or magenta cast. Glamour looks sit at the rosier end of that band on purpose.
