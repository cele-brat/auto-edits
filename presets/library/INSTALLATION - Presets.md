# INSTALLATION - Cele-Brat Lightroom Presets v1.0

Unzip CeleBrat_All_Presets.zip first. You will see six folders (Studio Looks - Presets, World Looks - Presets, Glamour Looks - Presets, Landscape Looks - Presets, Street Looks - Presets, Portrait Looks - Presets),
each containing one sub-folder per look with 5 .xmp files inside.

## A. Lightroom Classic (Mac / Windows) - recommended
1. Open Lightroom Classic and go to the Develop module (press D).
2. In the Presets panel on the left, click the "+" icon at the top of the panel and choose "Import Presets...".
3. Navigate to the unzipped folder. You can select the three pack folders at once (Lightroom imports every .xmp inside them), or select
   individual look folders, or individual .xmp files.
4. Click Import. The presets appear as groups named "Cele-Brat - <Look name> Look", each holding the 5 variations.
5. If a group does not appear, scroll the Presets panel or type "Cele-Brat" in the preset search field (Lightroom Classic 12+).
6. Manual alternative (if Import is greyed out): quit Lightroom and copy the look folders into
   Mac: ~/Library/Application Support/Adobe/CameraRaw/Settings/
   Windows: C:\Users\<your name>\AppData\Roaming\Adobe\CameraRaw\Settings\
   then restart Lightroom Classic. (Use Finder > Go > Library with the Option key held if the Library folder is hidden.)

## B. Lightroom (cloud / desktop app)
1. File > Import Profiles & Presets...
2. Select the .xmp files (or a whole look folder) and click Import.
3. They sync automatically to Lightroom on your other devices, including Lightroom Mobile, when you are signed in.

## C. Lightroom Mobile (iPhone / iPad / Android) - direct
1. Copy the .xmp files to the phone or tablet (AirDrop, Files app, Google Drive etc.).
2. Open any photo in Lightroom Mobile > Presets > tap the "..." (three dots) menu > Import Presets > choose the .xmp files.
3. A premium (paid) Lightroom Mobile subscription is required for preset import.

## D. Adobe Camera Raw / Photoshop
1. Open any raw file in Camera Raw (or Filter > Camera Raw Filter in Photoshop).
2. Open the Presets panel > "..." menu > Import Profiles & Presets > select the .xmp files.

## E. Updating or removing

- To update to a newer version, import the new files; same-named presets are replaced.
- To remove, right-click the group in the Presets panel > Delete Group, or delete the folder from the Settings path above.

## Requirements

- Lightroom Classic 13 or newer, Lightroom 7 or newer, Camera Raw 16 or newer (Process Version 15.4). Older versions may show the presets
  but ignore the newer colour grading sliders.

- Best results with the Adobe Color profile (the default for Nikon raws). If your import default is Camera Neutral / Standard, results will look flatter.
