How to edit

Preset

    Exported .xmp files, masks included. In Lightroom: right-click a preset, then Export.

    Adjust

    The same panels and order as Lightroom. Each slider starts at the preset's own value. Tick Auto to have a setting worked out for each photo; its slider then adds your own change on top. Double-click a slider to put it back.

    Your own masks

    Extra changes to one part of the photo, on top of any masks in the preset. Open a part, then move its sliders. Lightroom makes the final mask itself, so the edges you see here are approximate.

    Add photos from this computer

    Pick the wedding's folder. Raw files stay on this computer: only the preview stored inside each one is uploaded. Sub-folders (Haldi, Sangeet…) become event folders.

    Cull photos

    The server looks at focus, motion blur, exposure, closed eyes, expressions and near-identical shots, and rates each photo Keep, Maybe or Reject. Nothing is deleted. Ratings you set yourself are never changed.

    Change a rating yourself: select a photo and press 3 Keep, 2 Maybe, 1 Reject, 0 back to automatic.

    Export finished photos

    The server makes the JPEGs with each photo's look. You can close this window or the browser: it carries on.
