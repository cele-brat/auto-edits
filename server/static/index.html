          Lightroom Classic plug-in

          Download the Lightroom plug-in
          1. Download the plug-in and unzip it. Keep the AutoEdits.lrplugin folder somewhere it can stay (for example Documents).
          2. In Lightroom Classic: File › Plug-in Manager › Add, choose AutoEdits.lrplugin, then Done.
          3. Click Make a new key below and copy it. In Lightroom: Library › Plug-in Extras › Auto Edits: server settings, paste the key, Test connection, then OK.

          With the plug-in, Lightroom applies your edit to the RAW file in your catalogue: the sharpest finals. Works with Lightroom Classic on Mac and Windows.
